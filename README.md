# Career Roadmap AI

An AI-powered career guidance platform designed to help students explore career paths, follow structured learning roadmaps, discover projects and internships, and connect with mentors.

## Features

- Personalized career guidance using an AI assistant
- Student authentication and profile management
- Structured learning roadmaps and progress tracking
- Project recommendations
- Internship listings
- Mentor assignments and learning resources

## Technology Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Supabase
- **Database:** PostgreSQL (Supabase)
- **Authentication:** Supabase Auth
- **AI Assistant:** Gemini API through a Supabase Edge Function

## Team Development

This project is being developed collaboratively. Frontend and backend components are developed separately and integrated into the shared repository.

## Getting Started

1. Install Node.js.
2. Clone the repository.
3. Install dependencies using `npm install`.
4. Configure the required environment variables in `.env.local`.
5. Start the development server using `npm run dev`.

Do not commit environment files or API secrets to GitHub.
